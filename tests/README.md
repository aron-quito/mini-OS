# Tests de miniOS

Este directorio contendrá los scripts y ejecutables de pruebas automatizadas para:
- `Módulo 1`: Pruebas de procesos foreground, background y `ps-mini`.
- `Módulo 2`: Pruebas de concurrencia de hilos, verificación de 0 pérdidas con búfer circular.
- `Módulo 3`: Pruebas de First-Fit (coalescencia), cola de espera `mem_queue`, y paginación (`mem-translate`).
- `Integración`: Batería de pruebas automatizadas y análisis de memoria con Valgrind y Helgrind.
